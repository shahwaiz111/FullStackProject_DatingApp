# Full-Stack Web Application -- ASP.NET Core & Angular

## Overview

A full-stack web application built using ASP.NET Core Web API and Angular. it demonstrates the integration of a frontend application with a backend API, database operations,and user authentication.

## Technologies Used

- C#
- ASP.NET Core Web API
- Angular
- SQL Server
- Entity Framework Core
- JWT Authentication
- Git and GitHub

## Features

- RESTful API development
- Database operations using Entity Framework Core
- User authentication and authorization using JWT
- Angular frontend integrated with the backend API
- Dependency Injection

## How to Run

### Backend

1. Open the backend project in Visual Studio.
2. Configure your database connection string.
3. Run the ASP.NET Core Web API.

### Frontend

1. Open a terminal in the Angular project folder.
2. Run `npm install`.
3. Run `ng serve`.
4. Open the local URL shown in the terminal.
